# Face presence/recognition. PINNED BELOW 5 ON PURPOSE: OpenCV 5.0 removed

# The IANA timezone database, for the timezone setting (pc_skill.set_timezone).
# NOT optional on Windows: Windows ships no tz database at all, so
# zoneinfo.TZPATH is empty and EVERY zone name -- Europe/Berlin included --
# raises ZoneInfoNotFoundError without this. Pure data, no code, maintained by
# the Python core team. Absent, the clock silently falls back to machine local
# time (see pc_skill.resolve_timezone), which is correct but means the setting
# can never take effect.
tzdata                      # timezone database (Windows has none of its own)
keyboard                    # dictation, hotkeys
yt-dlp                      # youtube playback
# browser_skill's generic browser-control layer. Needs a one-time
# `playwright install chromium` after installing (downloads the browser

playwright
# vision_skill's OCR fallback (read_text/locate_text/click_text). Windows'

winrt-Windows.Graphics.Imaging
winrt-Windows.Storage.Streams
winrt-Windows.Foundation
winrt-Windows.Foundation.Collections
winrt-Windows.Globalization
